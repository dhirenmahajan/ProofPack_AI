# Superpower Skill

This skill enables Claude Code to perform tasks with enhanced capabilities, focusing on comprehensive code analysis, refactoring, and adherence to best practices.

## Usage

When invoked, Claude Code will:

1. Perform a deep analysis of the codebase, identifying areas for improvement in terms of performance, security, and maintainability.
2. Suggest and implement refactoring strategies to enhance code quality.
3. Ensure all changes align with the project's established conventions and standards, as defined in `CLAUDE.md`.
4. Prioritize changes that improve the overall architecture and scalability of the application.
5. Provide detailed explanations for all modifications and recommendations.
